# Welcome!
Welcome to our Human-AI collaboration pilot study!

We're doing a study on Human-AI collaboration and we're collecting data about user-agent interaction that focuses on data analysis. 

## What you will do?

You will need to finish 4 data analysis tasks with agent, each of them has a notebook containing a complete analysis made by the agent. 

You can decide whether you want to judge, or just accept the response from AI. You can check the notebook’s content, code, results, and visualizations for correctness, and answer the questions in the per-task form along the way. You are also welcome to edit the notebook when needed. Please use whatever process feels most natural and effective to you.

## Launcher

Run `claude-exp {group id} {task num}` to start the task. `{task num}` is from 1 ~ 4. 

## Task Format

Each task consists of the following components:

* **`input`**: A prompt based on the corresponding question in the form. The input may either preserve the original wording or be lightly rephrased for clarity while retaining the same meaning.
* **`response`**: The corresponding output for the given input.
* **`notebook`**: A Jupyter notebook containing the code used to analyze the task responses and generate the relevant results.
